# PhasmophobiAR

**PhasmophobiAR** is a mobile augmented-reality ghost-hunting game developed as a project for two separate courses at the Technical University of Munich:

- **3D User Interfaces [IN2111]**
- **Augmented Reality [IN2018]**

Players scan a real room and turn it into a haunted investigation space. Using printed marker cards, they place virtual tools such as an EMF reader, thermometer, spirit box, camera, and ghost trap. They must follow spatial clues, collect evidence, identify the ghost type, reveal it, and capture it before it disappears.

## Features

- Room-scale mobile AR gameplay
- Physical marker cards for placing investigation tools
- Multiple ghost types and evidence combinations
- Spatial visual and audio clues
- Ghost identification, capture, and journal system
- Horror events and jump scares

## Built With

- Unity
- AR Foundation
- ARCore and ARKit
- XR Interaction Toolkit
